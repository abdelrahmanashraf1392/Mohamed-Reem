# دعوة زفاف محمد & ريم

React + Vite + Bootstrap (واجهة أمامية فقط).

```bash
npm install
npm run dev      # تشغيل محلي
npm run build    # ناتج جاهز للرفع في dist/
```

كل المحتوى (الأسماء، المواعيد، الأماكن، الروابط، الصور، القصة) في ملف واحد: `src/data/wedding.js`.

- موسيقى: ضع ملف mp3 في `public/music` واكتب مساره في `music.src`.
- الحنّة: أضف `time` و`venue` و`address` و`mapUrl` الخاص بها في `events`.
